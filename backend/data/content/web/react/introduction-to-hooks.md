# Introduction to React Hooks

React Hooks were introduced in React 16.8 to allow developers to use state and other React features without writing class components.

Before Hooks, stateful logic and lifecycle methods were only available in class components, which often led to complex and hard-to-maintain code. Hooks solve this by enabling functional components to manage state and side effects.

## Why Hooks Exist
- Simplify component logic
- Reuse stateful logic
- Remove the need for class components
- Improve readability and maintainability

## Common Hooks
- useState
- useEffect
- useContext
- useRef
- useMemo
- useCallback
